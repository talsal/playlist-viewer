# playlist-viewer

אתר סטטי פשוט שמציג את הפלייליסטים של חיים סלמן ביוטיוב, עם השירים שבהם בצורה מסודרת וברורה.

## תכונות
- תצוגה נקייה ומודרנית של פלייליסטים ושירים
- ממשק בעברית (RTL)
- קובץ HTML יחיד, ללא תלויות חיצוניות

## הרצה
פשוט פתחו את `index.html` בדפדפן, או גשו לגרסה החיה דרך GitHub Pages.
